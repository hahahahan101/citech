# Citech Website

A lightweight, responsive, bilingual (English / Bahasa Indonesia) one-page website for Citech.

## Files
- `index.html` — website, styling, and interactions
- `favicon.svg` — browser icon
- `citech-mark.png` — cropped Citech logo mark used beside the wordmark in navigation and footer
- `robots.txt` — basic crawler instructions

## Before publishing
1. Open `index.html` in a code editor.
2. Search for `REPLACE_WITH_CITECH_EMAIL@example.com`.
3. The contact email is configured as `citechindonesiaofficial@gmail.com`.
4. Replace the illustrative portfolio previews with actual project screenshots and descriptions when available.
5. Review all copy, links, and service descriptions.

## Test locally
Double-click `index.html` to open it in a modern browser. The language switch, mobile navigation, and form validation work locally. The contact form prepares an email in the visitor's email app after `CONTACT_EMAIL` is configured.

## Publish using Netlify Drop
1. Create a Netlify account or sign in.
2. Open https://app.netlify.com/drop
3. Extract this ZIP file on your computer.
4. Drag the extracted `citech-website` folder into Netlify Drop.
5. Netlify will provide a public `netlify.app` URL.
6. To use a custom domain, purchase/own the domain and add it in the site's Domain settings, then follow Netlify's DNS instructions.

For regular updates, connect the project to a Git repository and deploy from Git so changes can be published automatically.
